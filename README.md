# Project_Galeri_Karya_Multimedia

Project Mata kuliah Block Chain dan AI yang mengategorikan karya menggunakan AI dan menerbitkan asetnya melalui kontrak ERC-721 oleh kurator.
cara menjalankan di lokal:
Terminal 1 :
"cd blockchain
npm run node"
Terminal 2 :
"cd frontend
npm run dev"
Terminal 3 :
"cd backend-ai
.\venv\Scripts\Activate.ps1
python run.py"
Terminal 4 :
"cd blockchain
npm run deploy:sepolia"
